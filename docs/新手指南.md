# 新手指南 · 从双击到上线（零基础）

这份指南写给**完全不懂编程**的人。你只需要**双击一个文件**，剩下的跟着网页里的按钮走。

> 全程不用打开“终端”敲命令。

---

## 一、准备（拿到发布包）

你会拿到一个压缩包 **`Blog.zip`**。双击解压，得到一个文件夹，里面有：

| 文件 | 用途 |
|------|------|
| **Start-Blog.app** | 苹果电脑（macOS）双击它 —— 像打开一个软件，没有黑窗口 |
| **Start-Blog.vbs** | Windows 双击它 —— 后台悄悄启动，没有黑窗口 |
| Start-Blog.command / Start-Blog.bat | 备用启动方式（会显示一个文字窗口） |
| `bin/` | 程序本体（有它就不用装任何开发环境） |
| `docs/新手指南.md` | 就是本文 |

把整个文件夹放到你容易找到的地方，比如“文稿”或桌面。**不要只把单个文件拖出来**，要整个文件夹一起。

> 不用找“停止”按钮：关掉所有博客网页后，它会在约 1 分钟后自动停止。想立刻用最新版本，再次双击 Start 即可（会让你选“打开”或“重启”）。

> 没有 GitHub 账号？先去 https://github.com 免费注册一个（邮箱+密码即可），再回来。发布到网上需要它。

---

## 二、第一次启动

### 苹果电脑（macOS）
1. 双击 **Start-Blog.app**。
2. 第一次可能提示“无法打开，因为来自身份不明的开发者”：
   - **右键**点 `Start-Blog.app` → **打开** → 再点 **打开**；或
   - 系统设置 → 隐私与安全性 → 底部“仍要打开”。
3. 浏览器会**自动打开**向导页。**没有黑窗口、Dock 里也没有常驻图标**——博客就在后台运行。

> 停止博客：不用手动停。关掉所有博客网页后约 1 分钟自动停止。
> 想立刻用最新版本：再次双击 **Start-Blog.app**，会弹出选择——“打开网页”或“重启”。

### Windows
1. 双击 **Start-Blog.vbs**。
2. 若弹出蓝色“Windows 已保护你的电脑”：点 **更多信息** → **仍要运行**。
3. 稍等一两秒，浏览器**自动打开**向导页。**没有黑窗口**——博客在后台运行。

> 停止博客：不用手动停。关掉所有博客网页后约 1 分钟自动停止。
> 想立刻用最新版本：再次双击 **Start-Blog.vbs**，会问你“打开(是) / 重启(否) / 取消”。

浏览器会打开一个叫 **“一步步上线你的博客”** 的向导页（网址类似 `http://localhost:8080/setup`；若 8080 被占用会自动换 8081、8082……，以浏览器实际打开的地址为准）。接下来全在这个网页里点按钮。

## 三、跟着网页向导走（6 步）

向导页每一步都有状态灯：**✓ 绿色**表示没问题，**✗ 红色**表示需要点旁边的按钮处理。

### ① 环境检测
检查两个小工具：
- **Git**：管理文件版本。
- **GitHub CLI**：用来连你的 GitHub 账号（不用记密钥）。

如果显示 ✗，点旁边的按钮，程序会自动帮你装好，**不需要 Homebrew 等任何其他软件**：
- **Git**：macOS 会弹出系统自带的对话框，点“安装”；Windows 会自动下载安装。装完回网页点 **↻ 重新检测**。
- **GitHub CLI**：点 **一键下载 GitHub CLI**，程序会直接从 github.com 下载官方版本（约 10–15MB）放到本机，无需再装别的东西。完成后点 **↻ 重新检测**。

### ② 连接 GitHub 账号
点 **用浏览器登录 GitHub**：
- 网页会显示一个**一次性代码**（像 `ABCD-1234`），并打开 GitHub 授权页。
- 把代码粘进去，点授权。完成后回向导页点 **↻ 重新检测**，状态变绿即可。

> 这一步之后，就不用再输 GitHub 密码了。

### ③ 创建代码仓库
- 给博客起个名字，默认 `blog`（会成为网址的一部分）。
- 仓库会创建为**公开（Public）**：GitHub Pages 免费版只能发布公开仓库，所以不提供“私有”选项。
- 点 **创建 / 关联仓库**。

### ④ 写文章 / 本地预览
- 进入后台（`/admin`）——**无需登录、没有密码，直接打开**——填个人资料、经历、项目、文章、足迹、瞬间。
- 随时点 **本地预览首页** 看效果——**保存即生效，不用重新构建**。

### ⑤ 发布到网上
- 回到向导页（浏览器地址栏输 `/setup` 即可，或从后台链接过去）。
- 点 **🚀 一键发布上线**。它会把你的内容渲染成静态网页、推送到 GitHub、开启 GitHub Pages。
- 稍等 1–2 分钟，页面会显示你的**网站地址**（形如 `https://你的用户名.github.io/blog/`），点开就是你的博客！

---

## 四、以后怎么用

1. 双击启动器（macOS 的 `Start-Blog.app` / Windows 的 `Start-Blog.vbs`）。
2. 在后台写/改内容，本地预览满意。
3. 打开 `/setup` 第 ⑤ 步，点 **一键发布上线**。

就这三步。**不发布，改动只在本地；发布后，全世界都能看到。**

> 提示：如果博客已经在运行，再次双击启动器不会重复开一个，而是直接帮你打开网页。

---

## 五、你的内容存在哪 / 怎么备份

你的**全部内容**都保存在一个文件里：

- macOS / Windows：**你的主目录下的 `dev-home-blog/blog.db`**
  - macOS 大致是 `/Users/你的用户名/dev-home-blog/blog.db`
  - Windows 大致是 `C:\Users\你的用户名\dev-home-blog\blog.db`

想备份就复制这个 `blog.db`；想换电脑就把它拷到新电脑同样的位置。

## 六、常见问题

| 现象 | 怎么办 |
|------|--------|
| 双击没反应 / 提示身份不明 | 见上面“第一次启动”的解锁步骤（macOS 右键打开；Windows 仍要运行）。 |
| 浏览器没自动打开 | 手动在地址栏输入 `http://localhost:8080/setup`（若端口被占用，程序会自动换成 8081、8082…，以浏览器实际打开的地址为准）。 |
| 怎么停止博客 | 不用手动停。关掉所有博客网页后约 1 分钟自动停止。 |
| 更新了程序想立刻生效 | 再次双击 Start（macOS 是 Start-Blog.app，Windows 是 Start-Blog.vbs），选择“重启”即可用最新版。 |
| 再次双击好像没开新的 | 正常。已在运行时会弹出选择：打开网页 / 重启 / 取消，避免开两个损坏数据。 |
| 打不开后台 | 后台无需登录、没有密码，直接访问 `http://localhost:8080/admin` 即可。 |
| 发布后网址打不开 | GitHub Pages 首次启用要等 1–2 分钟；刷新几次。 |
| 想换台电脑 | 把 `dev-home-blog/blog.db` 拷到新电脑的同样位置即可。 |
