# Footprint 地图交互、懒加载与返回状态设计

> 日期：2026-07-29  
> 分支：`personal-blog`  
> 状态：设计已确认，待实现

## 一、目标

本次改造聚焦 Footprint 地图的三个问题：

1. 将“单击即下钻”改为“单击选中、双击或手机双点下钻”。
2. 单击省份或城市时展示对应层级的全部非空 `note`，并保留关联瞬间。
3. 降低公开博客首次下钻的等待时间，同时在返回上一级时完整恢复此前的缩放、平移和选中状态。

不改变 Footprint 的三级数据模型：国家 → 省份 → 城市。

## 二、层级术语

产品层级与当前 `globe.js` 内部名称不同，实施时按下表对应：

| 产品层级 | 当前 `state.layer` | 画面 |
|---|---|---|
| 国家层级 | `globe` | 旋转地球与国家标记 |
| 省份层级 | `country` | 某个国家的省/州平面地图 |
| 城市层级 | `city` | 某个省/州的城市平面地图 |

后续代码可以保留现有内部枚举，但新增方法、测试名称和设计注释应明确产品层级，避免把 `country` 误解为国家层级。

## 三、交互规则

### 3.1 国家层级

- 单击国家：
  - 高亮并固定选中该国家。
  - 不下钻。
  - 不展示 Footprint `note`。
  - 展示该国家下所有城市关联瞬间的去重合集。
- 双击同一国家，或手机连续双点同一国家：
  - 下钻到该国家的省份地图。
- 双击空白位置或不同国家不下钻。

### 3.2 省份层级

- 单击省份：
  - 高亮并固定选中该省份。
  - 不下钻。
  - 展示该省份下所有城市的非空 `note`。
  - 在笔记下方继续展示该省份关联瞬间的去重合集。
- 双击同一省份，或手机连续双点同一省份：
  - 该省份存在下一级地图时，下钻到城市地图。
  - 不存在下一级地图时，只维持选中状态。
- 双击空白位置或不同省份不下钻。

### 3.3 城市层级

- 单击城市：
  - 高亮并固定选中该城市。
  - 展示该城市的全部非空 `note`。
  - 在笔记下方继续展示该城市关联瞬间的去重合集。
- 城市是最后一级，双击或双点不执行额外动作。

### 3.4 单击与双击判定

- 第一次有效点击立即完成选中和内容展示，不等待双击窗口结束。
- 第二次点击仅在以下条件同时满足时触发下钻：
  - 位于双击时间窗口内。
  - 命中同一层级、同一个区域。
  - 两次点击之间没有发生拖动、平移、滚轮缩放或双指缩放。
- 桌面鼠标双击与移动端双点使用同一套区域级判定，不依赖浏览器原生 `dblclick` 完成业务下钻。
- 原有“双击重置缩放”能力移除；用户通过滚轮或双指手势缩回。

## 四、笔记与瞬间展示

### 4.1 面板顺序

地图下方按固定顺序展示：

1. 足迹笔记
2. 关联瞬间

两个区域独立显示。某一类内容为空时，只隐藏对应区域，不显示空状态占位。

### 4.2 笔记聚合

- 国家：不聚合、不展示笔记。
- 省份：遍历该省份下所有城市，保留每一条非空 `note`。
- 城市：保留该城市的每一条非空 `note`。
- 同一城市存在多条 Footprint 记录时，全部展示，不覆盖、不自动去重。
- 省份笔记按 Footprint 原始顺序展示，并附城市名称。
- 城市笔记只显示该城市名称和内容。
- 所有文本通过安全的 HTML 转义后渲染。

### 4.3 瞬间聚合

- 国家：聚合该国家所有省份、城市的 `momentIds`。
- 省份：聚合该省份所有城市的 `momentIds`。
- 城市：聚合该城市所有 Footprint 记录的 `momentIds`。
- 同一个瞬间 ID 只展示一次，并保持首次出现顺序。
- 点击瞬间后沿用现有行为：滚动到对应瞬间并短暂高亮。

## 五、导航状态与返回恢复

### 5.1 状态快照

每次成功下钻前，将当前层级压入导航栈。快照至少包含：

- 当前层级。
- 当前国家和省份上下文。
- 当前地图数据引用。
- 地球旋转角度、惯性和缩放比例。
- 平面地图缩放比例与横纵平移量。
- 当前选中区域和悬停区域。
- 当前显示的笔记与瞬间所依赖的选中状态。

笔记和瞬间不单独复制 HTML；恢复选中状态后由统一渲染函数重新生成，避免界面状态与数据状态分离。

### 5.2 下钻事务

下钻按事务方式执行：

1. 保持当前层级、缩放、选中项和内容面板不变。
2. 请求或等待下一层地图数据。
3. 数据成功后，保存当前快照并切换到下一层。
4. 数据失败时，不压栈、不切层，显示可重试提示。

因此慢网或请求失败不会出现空白地图，也不会污染返回历史。

### 5.3 返回入口

以下入口统一调用同一个历史恢复函数：

- 左上角返回按钮。
- 面包屑导航。
- 移动端横向滑动返回。

从城市返回省份、从省份返回国家时，恢复下钻前的完整快照，包括：

- 缩放比例。
- 平移位置。
- 地球旋转位置。
- 选中区域。
- 足迹笔记。
- 关联瞬间。

面包屑跨两级返回时，按历史栈逐级弹出到目标层级，不重新创建默认状态。

## 六、分阶段懒加载

### 6.1 首屏阻塞资源

首屏只等待：

- `world.json`
- `/api/footprints`

国家地球首次绘制完成前，不请求任何省份或城市地图。Footprint 之外的首页模块不等待地图后台队列。

### 6.2 首屏完成后的后台队列

国家地球完成首次绘制后，在浏览器空闲时间启动后台队列：

1. 第一轮加载 Footprint 中出现过的国家省份地图。
2. 某国家省份地图就绪后，将该国家可下钻的城市级地图加入第二轮队列。
3. 第二轮中，有 Footprint 记录的省份优先，其他可下钻省份随后加载。
4. 后台请求并发上限为 2，避免争抢首页图片、字体和其他模块带宽。

支持 `requestIdleCallback` 时使用空闲调度；不支持时使用短延迟定时器回退。

### 6.3 主动操作优先级

用户双击下钻时：

- 数据已缓存：立即切换。
- 请求正在进行：复用同一个 Promise，不重复请求。
- 尚未开始：将目标提升到最高优先级并立即请求。
- 已失败：允许用户再次双击重试。

用户悬停或单击可下钻区域时，可以提前提升该区域的下一层任务，但仍受并发上限约束。

### 6.4 暂停条件

以下条件暂停新的后台预取任务：

- 页面处于后台。
- 浏览器离线。
- `navigator.connection.saveData` 为真。

暂停只影响预取；用户主动下钻始终可以发起请求。页面恢复可见或网络恢复后继续队列。

## 七、请求去重与缓存

### 7.1 页面内请求缓存

统一地图加载器维护三种状态：

- `queued`：已进入后台队列。
- `pending`：请求进行中，保存 Promise。
- `fulfilled`：请求完成，保存解析后的地图对象。

后台预取、悬停预取、单击预取和主动下钻必须经过同一加载器。相同 URL 在同一页面生命周期内最多存在一个网络请求。

失败请求从 `pending` 中移除并记录错误状态，使后续主动操作可以重试。

### 7.2 浏览器与 CDN 缓存

- 发布后的地图 JSON 使用长期缓存。
- 地图 URL 附带资源版本参数；地图内容或生成逻辑变化时版本变化，自动绕过旧缓存。
- 本地开发环境仍允许及时看到资源更新，不能因为长期缓存而固定旧版 JS 或地图。
- 静态发布和本地服务必须生成相同的版本化 URL 规则。

## 八、加载反馈与错误处理

- 后台预加载不显示提示。
- 用户主动下钻且目标尚未就绪时：
  - 保留当前地图和当前选择。
  - 在地图上显示轻量提示：“正在加载下一级地图…”。
- 加载成功后再切换层级。
- 加载失败：
  - 保持当前视图不变。
  - 提示：“加载失败，双击重试”。
  - 不压入导航历史。
- 若用户在等待期间选择了其他区域，旧请求可以继续进入缓存，但完成后不得自动切换到已经失效的目标。

## 九、组件边界

主要改动集中在：

- `web/static/js/globe.js`
  - 选中与双击判定。
  - 笔记/瞬间聚合和渲染。
  - 导航历史栈。
  - 统一加载器和后台优先级队列。
  - 加载反馈与失效下钻保护。
- `web/templates/public/home.html`
  - 新增足迹笔记容器；保留现有瞬间容器。
- `web/static/css/crt.css`
  - 足迹笔记、加载提示、选中反馈样式。
- `internal/server/routes.go`
  - 区分可长期缓存的地图 JSON与需要及时刷新的代码资源。
- 静态导出/资源版本相关代码
  - 为本地服务和静态导出提供一致的资源版本。
- 测试文件
  - 为纯状态与聚合逻辑增加可重复测试。
  - 扩展浏览器交互测试覆盖单击、双击、加载和返回。

不改变数据库 schema，也不改变 `/api/footprints` 的既有嵌套结构。

## 十、验证与验收

### 10.1 交互验收

- 单击国家只选中并展示国家关联瞬间，不下钻、不展示笔记。
- 双击或手机双点同一国家才进入省份地图。
- 单击省份展示该省所有非空笔记，再展示关联瞬间。
- 双击或双点同一可下钻省份才进入城市地图。
- 单击城市展示该城市全部非空笔记，再展示关联瞬间。
- 单击不同区域、拖动、滚轮缩放和双指缩放不会误触下钻。
- 城市层级双击无额外动作。
- 原有双击重置缩放行为不存在。

### 10.2 状态验收

- 放大并平移省份地图后进入城市，再通过返回按钮返回，省份视图完全恢复。
- 通过面包屑和移动端横滑返回得到相同结果。
- 返回后选中省份、笔记和瞬间列表仍与下钻前一致。
- 加载失败时层级、缩放、平移、选中和历史均不改变。

### 10.3 性能验收

- 首屏国家地球首次绘制前，不请求省份或城市地图。
- 首屏绘制完成后才启动后台请求。
- 后台请求并发数不超过 2。
- 后台预取和用户主动下钻同一 URL 时，网络层只出现一次请求。
- 用户主动目标可越过后台队列优先加载。
- 页面隐藏、离线或节省流量模式下不启动新的后台预取。
- 地图 JSON 在公开站点可被浏览器/CDN 长期缓存，版本变化后能获取新内容。

### 10.4 回归验证

- `go test ./...`
- `node scripts/globe_logic_test.mjs`
- 浏览器交互测试：桌面鼠标、移动端触控模拟、慢网和失败重试。
- 静态导出后验证根路径和带 `BASE_URL` 子路径的地图请求。

## 十一、非目标

- 不新增第四级地图。
- 不修改 Footprint 后台录入模型或数据库结构。
- 不一次性把约 2 MB 的全部地图数据并入首屏包。
- 不为城市层级增加继续下钻行为。
- 不新增独立的“重置视图”按钮。
