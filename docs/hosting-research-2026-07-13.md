## 一、结论速览

- 本项目最终支持三平台镜像：**Cloudflare Pages（海外/全球）+ 腾讯云 EdgeOne Pages
  （国内加速）+ Gitee Pages（国内备选）**。
- **一次发布覆盖 Cloudflare + EdgeOne**：两者都连同一个 GitHub 仓库，`git push` 后各自
  自动部署。运行 `./scripts/publish.sh` 即可。
- **Gitee 单独走 `./scripts/publish-gitee.sh`**：因为它是子路径托管且免费版不自动部署。
- 国内访问顺畅度（免费方案，调研当日认知）：**EdgeOne ≈ Gitee > Cloudflare > GitHub 直连**。

## 三、逐平台要点

### Cloudflare Pages（海外/全球，本项目已配置）
- 运营方：Cloudflare（美国）。个人使用真免费，流量不限、构建约 500 次/月。
- 连 GitHub 仓库，push 即自动部署；根路径，本项目无需改造。
- 国内访问：免费版**无中国大陆节点**，走海外节点，能访问但不如国内平台稳。
- 免备案：用送的 `xxx.pages.dev` 域名免备案。

### 腾讯云 EdgeOne Pages（国内加速，推荐国内镜像）
- 运营方：腾讯云（中国）。有**长期免费套餐**，据官方称含中国大陆访问、直连 ISP、
  3200+ 节点，实测比 GitHub Pages 快数倍。
- 连 GitHub 仓库，push 即自动部署；根路径，本项目无需改造。
- ⚠️ 需实测/留意：
  - 曾有「预览域名有效期 3 小时」的公测期说法，**可能已变动**，以控制台为准。
  - 国内加速区**绑自定义域名需 ICP 备案**；用平台默认域名可免备案。
  - 免费额度含每月定额函数调用 / KV / 构建次数，超出计费。

### Gitee Pages（国内备选，坑较多）
- 运营方：开源中国 OSCHINA（中国）。个人公开仓库免费。
- **三个关键限制**：
  1. **免费版不自动部署** —— 每次 push 后需到「仓库 → 服务 → Gitee Pages」手动点“更新”。
     自动部署属付费 Gitee Pages Pro。
  2. **子路径托管** —— 默认地址 `https://<user>.gitee.io/<repo>/`。本项目原用绝对路径，
     已加 `BASE_URL` 子路径支持，用 `publish-gitee.sh` 构建带前缀的版本解决。
  3. 需 **实名认证**才能开 Pages；自定义域名需备案；频繁更新可能触发风控审核。

## 四、本项目的落地方式

代码层面已做的支持：
- 导出命令支持 `BASE_URL` 前缀：`./blogbin export <dir>`（根路径）与
  `BASE_URL=/repo ./blogbin export <dir>`（子路径）。
- 前端 `globe.js` 读取 `window.__BASE__` 前缀所有数据请求；模板用 `{{.Base}}` 前缀所有
  资源与链接。已验证根路径与 `/myblog/` 子路径下页面、静态资源、地球数据均 200。

发布脚本：
- `./scripts/publish.sh` → 构建根路径 `dist/` → push 到 GitHub → Cloudflare + EdgeOne 自动部署。
- `./scripts/publish-gitee.sh <repo>` → 构建 `BASE_URL=/<repo>` 子路径站 → 强推到 Gitee 远端
  分支 → 之后手动在 Gitee 点“更新”。

## 五、备案与自定义域名（通用提醒）

- 所有「国内加速区 + 自定义域名」的免费平台（EdgeOne / Gitee / 国内 CDN）绑**自己的域名**
  基本都要 **ICP 备案**。
- 想**完全免备案**：使用各平台送的默认域名（`*.pages.dev` / EdgeOne 默认域名 /
  `*.gitee.io`），国内同样可访问，只是域名非自有。
